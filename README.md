## О программе

С ростом игровых библиотек на компьютере каждый игрок сталкивается с **«параличом выбора»**: десятки и сотни игр установлены в системе, но вместо приятного отдыха вечер уходит на бесцельное листание списков.

**PlayPick** решает эту проблему:
- Объединяет игры из разных источников (Steam, Epic Games Store, GOG Galaxy, произвольные папки и отдельные `.exe`) в единый упорядоченный локальный каталог.
- Позволяет мгновенно отфильтровать коллекцию по жанрам, тегам, статусу установки или «Избранному».
- Выбирает игру с помощью одной из 5 анимаций рулетки с учётом настраиваемых весов вероятности.
- Запускает выбранную игру вручную, с настраиваемым таймером отмены или мгновенно.

Приложение полностью автономно, не требует создания учётных записей и сохраняет всю библиотеку в быстрой локальной базе данных **SQLite**.

## Возможности

- **5 режимов рулетки выбора**:
  1. *Последовательная*: циклическая подсветка карточек в основном списке сверху вниз с постепенным замедлением до выбранной игры.
  2. *Случайная*: хаотичные скачки подсветки по случайным карточкам списка с плавным торможением.
  3. *Кейсы*: оверлей с эффектной анимацией открытия кейса и плавным появлением выпавшей игры.
  4. *Горизонтальная рулетка*: горизонтальная прокрутка ленты обложек со стрелкой-указателем по центру.
  5. *Вертикальная рулетка*: вертикальный круговой барабан со стрелками по бокам в стиле слот-машины.
- **Интеллектуальная система весов (Избранное)**:
  - Поддержка как положительного бонуса (до +500%), так и отрицательного снижения вероятности (вплоть до -100% для полного исключения избранных игр из случайного выбора).
  - Ползунок быстрой настройки от -100% до +100% с шагом 5% и поле ручного ввода произвольного процента.
  - Наглядный расчёт итогового множителя шанса прямо в интерфейсе.
- **3 режима запуска после завершения выбора**:
  - *Подтверждение*: карточка результата ожидает нажатия кнопки «Запустить игру» пользователем.
  - *Обратный отсчёт*: показ карточки с настраиваемым таймером (по умолчанию 5 секунд, регулировка от 1 до 15 сек) и заметной кнопкой отмены до момента старта.
  - *Автоматический*: мгновенный запуск исполняемого файла игры сразу после остановки барабана.
- **Надёжная дедупликация и нормализация путей**:
  - Нормализация путей Windows: устранение различий в прямых и обратных слешах (`/` и `\`), регистре букв, относительных сегментах и кавычках.
  - При повторном добавлении уже существующего `.exe` файл не дублируется: запись аккуратно обновляется, дополняются недостающие жанры и теги без потери пользовательских данных.
- **Гибкая фильтрация коллекции**:
  - Множественный выбор жанров и пользовательских тегов.
  - Переключатель логики объединения тегов: «Любой тег» (OR) или «Все теги» (AND).
  - Фильтр недавних игр (исключение запускавшихся за последние N дней).
- **Синтезированное аудиосопровождение**:
  - Щелчки барабана и победный аккорд, генерируемые процедурно через Web Audio API (без внешних тяжёлых аудиофайлов и без задержек).

## Настройки приложения

В разделе **«Настройки»** доступны следующие параметры:

| Параметр | Описание | Диапазон и управление | Значение по умолчанию |
| :--- | :--- | :--- | :--- |
| **Режим анимации** | Визуальный стиль жеребьёвки | 5 режимов (кнопки выбора) | `Последовательная` |
| **Длительность анимации** | Время прокрутки до победной игры | Ползунок: `0 – 10 сек` (шаг 0.25с)<br/>Ручной ввод: `до 60 сек` (`0 сек` = мгновенно) | `5.0 сек` |
| **Влияние избранного** | Изменение шанса выпадения игр с сердечком | Ползунок: `-100% – +100%`<br/>Ручной ввод: `до +500%` | `0%` (равные шансы) |
| **Способ запуска** | Поведение после остановки выбора | `Подтверждение` / `Обратный отсчёт` / `Автоматический` | `Подтверждение` |
| **Задержка отсчёта** | Время ожидания перед автозапуском (при режиме отсчёта) | Ползунок: `1.0 – 15.0 сек`<br/>Ручной ввод текста | `5.0 сек` |
| **Звуки рулетки** | Звуковое сопровождение вращения и победы | Переключатель (вкл/выкл) | `Включено` |
| **Звуки уведомлений** | Мягкий сигнал при системных предупреждениях | Переключатель (вкл/выкл) | `Включено` |
| **Ключ SteamGridDB** | Загрузка вертикальных постеров высокого разрешения | Текстовое поле (опционально) | *Не задан* |
| **Ключ RAWG API** | Получение расширенных описаний и жанров | Текстовое поле (опционально) | *Не задан* |

## Добавление игр и источники данных

PlayPick предоставляет прозрачную систему наполнения библиотеки:

### 1. Поддержка платформ и сканирование
- **Steam**: автоматическое сканирование через чтение реестра Windows, файла манифеста библиотек `libraryfolders.vdf` и локальных файлов `appmanifest_*.acf` на всех подключённых дисках.
- **Epic Games Store**: автоматическое чтение локальных манифестов `.item` из каталога `ProgramData\Epic\EpicGamesLauncher\Data\Manifests`.
- **GOG Galaxy**: автоматическое обнаружение через реестр Windows (`SOFTWARE\GOG.com\Games`) и манифесты `goggame-*.info`.
- **Любые папки на диске**: кнопка *«Сканировать папку»* выполняет рекурсивный поиск корневых `.exe`, автоматически игнорируя служебные утилиты (`unins000.exe`, `crash_reporter.exe`, `dxwebsetup.exe`, `UnityCrashHandler.exe` и др.).
- **EA app и Ubisoft Connect**: прямое автоматическое сканирование реестра для данных лаунчеров ограничено; игры добавляются вручную через выбор исполняемого файла `.exe`.

### 2. Получение постеров и метаданных
1. **Steam Store CDN**: для игр со `steamAppId` постеры `600x900` загружаются напрямую из открытого CDN Valve **без необходимости регистрации и без API-ключей**.
2. **Извлечение системных иконок**: для сторонних `.exe` и ярлыков `.lnk` PlayPick извлекает нативную крупную иконку с помощью системного API Electron.
3. **SteamGridDB API**: при указании бесплатного персонального API-ключа загружаются качественные фанатские вертикальные постеры.
4. **RAWG API**: при указании персонального ключа загружаются жанры и описания для неизвестных каталогу игр.

## Установка

Готовый установщик доступен на странице релизов:

1. Откройте [**GitHub Releases**](https://github.com/notsons-git/PlayPick/releases/tag/v0.1.1-beta).
2. Скачайте файл **`PlayPick-Setup-0.1.1.exe`**.
3. Запустите установщик и следуйте стандартным шагам мастера Windows.
4. Запустите PlayPick через ярлык на рабочем столе или меню «Пуск».

## Сборка из исходного кода

Для сборки потребуется **Node.js** (версии 18 или выше) и пакетный менеджер **npm**:

```bash
# 1. Клонирование репозитория
git clone https://github.com/notsons-git/PlayPick.git
cd PlayPick

# 2. Установка зависимостей
npm install

# 3. Запуск в режиме разработки (Vite + Electron)
npm run dev

# 4. Запуск юнит-тестов
npm test

# 5. Проверка типов TypeScript
npm run typecheck
npm run typecheck:electron

# 6. Сборка готового Windows-установщика (NSIS x64)
npm run build:dist
```

Собранный файл установщика помещается в каталог `release/`.

## Данные и конфиденциальность

- **Хранение данных**: Вся база данных приложения (игры, пользовательские теги, история, кеш метаданных и настройки) сохраняется локально в стандартной системной папке пользователя:
  ```
  %APPDATA%\playpick\playpick.db
  ```
- **Полная конфиденциальность**: В приложении **нет телеметрии, аналитики и трекеров**. Никакие сведения о вашей системе, времени игры или коллекции не отправляются третьим лицам.
- **Сетевая активность**: Сетевые запросы осуществляются исключительно для загрузки обложек (Steam CDN, SteamGridDB, RAWG) и только по прямым URL изображений.
